The Factory Floor — Test Questions
===================================
Questions to paste into the Streamlit app's "Describe the maintenance problem" box,
to exercise the RAG pipeline and (for the VFD ones) the equipment_type filter tied
to the machine selector.

IMPORTANT — every fault code below is REAL and VERIFIED: extracted directly from the
ingested Siemens SINAMICS G120/G120C List Manual PDFs (regex extraction over the raw
PDF text, cross-checked with exact-string matches against the vector store), and each
one confirmed to retrieve a grounded, correct answer through the app's RAG pipeline.
Also note: bare fault-code queries ("F30021?") retrieve poorly on their own — always
pair the code with a short symptom description, as done below, since that's both
more realistic (a technician naturally mentions both) and what the retriever actually
needs to find the right page.

Electric motor manuals do NOT use a numeric fault-code system at all (confirmed: zero
matches for any F/A + digits pattern across all 5 motor manuals) — motor issues here
use real terminology from those manuals instead (abnormal/unusual noise, insulation
resistance, condensation, re-greasing per lubricant plate, direction of rotation with
motor uncoupled, etc.), not fault codes.

Tip: pick an electric motor (MOTOR-01..10) in the sidebar before asking the motor
questions, and a VFD (VFD-01..10) before asking the VFD questions, so the RAG search
stays restricted to the right manual family.
